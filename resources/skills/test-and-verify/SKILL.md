# Test & Verify

Prove the change with the checks this project actually has.

1. Read package.json scripts and nearby tests with read_file and search_tests. Choose run_tests, run_typecheck, run_linter, or a build via terminal only when that check exists.
2. Run the selected checks. A missing runner is not applicable, not a pass.
3. Report each command and the result it returned. Do not say verified, green, or done when that check was not run.
4. If a check fails, report the failure. Do not treat a failed or skipped check as success.
