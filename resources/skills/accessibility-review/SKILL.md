# Accessibility Review

Review what the page exposes. Separate advice from blockers.

1. Use the existing ORVYN Browser session from browser_open. Do not create a second browser.
2. Open the page and capture browser_screenshot. Inspect visible labels, headings, and contrast from that screenshot. That screenshot is real browser evidence.
3. Check keyboard usability and focus by using the controls in the same session. Do not claim a focus order you did not observe.
4. Mark each note as a recommendation or a blocking defect. Do not upgrade a suggestion into a defect without session evidence.
