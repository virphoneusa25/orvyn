# Frontend Design

Improve the UI inside the product's existing design language.

1. Read the current layout, components, and styles with read_file and search_codebase before changing them.
2. Edit with edit_file. Match existing type, color, spacing, and components. Do not restyle the product into a generic template.
3. When browser tools are available, open the page with browser_open, capture browser_screenshot, and read browser_console_errors.
4. If a screenshot was not taken, say visual verification was not completed. Do not describe a screen you did not capture.
