# React Best Practices

Change React code the way this project already does.

1. Read the neighboring components, data loading, and styling with read_file and search_codebase before editing.
2. Keep the project's component, state, and rendering patterns. Do not add a state library or a new file layout.
3. Edit with edit_file. Fix rendering and data flow in the component that owns them.
4. Run run_typecheck, and run_tests when component tests exist. Report the result. Do not add a React toolchain the repo does not use.
