# Ship code with proof

Edit the project, then prove the change with tests before claiming done.

## Steps

1. Inspect with search_codebase / read_file before editing.
2. Make the smallest change that fixes the request.
3. Run tests or typecheck. If they fail, diagnose and retry.
4. Do not finish while tests are red or unrun when the user asked to verify.

## Gate

run_tests or test.completed passed
